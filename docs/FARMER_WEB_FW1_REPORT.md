# Farmer Web FW-1 — read-only implementation report

## Product split

Farmer Web is a separate UX shell in the existing React application. It shares
Supabase Auth, the centralized FastAPI client, domain mappers, formatting and
design tokens with Management Web, while keeping farmer navigation and
information density separate.

```text
farmer                 → /farmer
cooperative_manager    → /dashboard
enterprise / regulator → /dashboard
```

Routing is an UX decision only; FastAPI and Supabase RLS continue to enforce
scope.

## Routes and APIs

| Route | Screen | FastAPI reads |
|---|---|---|
| `/farmer` | current season, metric summary, recent journal | farms, farm plots, plot crop seasons, season metrics, activities |
| `/farmer/journal` | current-season journal | hierarchy + season activities |
| `/farmer/farms` | farmer farm/plot cards | farms, farm plots, plot crop seasons |
| `/farmer/farms/:farmId` | farmer farm detail | farm, farm plots |
| `/farmer/plots/:plotId` | plot and seasons | plot, plot crop seasons |
| `/farmer/crop-seasons/:id` | season overview | crop season, plot, metrics, activities |
| `/farmer/crop-seasons/:id/journal` | season timeline | activities |
| `/farmer/crop-seasons/:id/performance` | season performance | metrics |
| `/farmer/crop-seasons/:id/carbon` | simplified Carbon result/empty state | crop-season carbon |
| `/farmer/performance` | active-season metrics | hierarchy + metrics |
| `/farmer/account` | minimal identity/logout | current Supabase session |

No browser call reads Supabase business tables directly. No Farmer write,
recommendation, CV, MRV administration, or Carbon recalculation control was
implemented.

## UX decisions

- Five low-density destinations: Tổng quan, Nhật ký, Ruộng, Hiệu suất, Tôi.
- Desktop uses a compact farmer rail; mobile uses labelled bottom navigation.
- A current season is selected only from backend status `active` or the existing
  Vietnamese active-state wording. Missing active state is an explicit empty
  state, never a guessed season.
- Quick-entry controls are disabled and labelled `Sắp có`; no mutation is
  hidden behind them.
- `null` remains `Chưa đủ dữ liệu`; explicit backend zero remains zero.
- Cost is labelled `Chi phí vật tư đã ghi nhận`, not total production cost.
- Expected `no_calculation` Carbon 404 is a calm domain empty state. Success
  UI shows only farmer-level total/intensity/source information; it does not
  expose audit provenance by default.

## FW-2 prerequisite

Read-only FW-1 intentionally stops before activity mutations. FW-2 requires
the approved `FARMER_WEB_WRITE_CONTRACT.md` to become a separately approved
versioned FastAPI change: idempotency migration, transaction-capable activity
repository, RLS/scope tests, then create/update/delete UI.
